# IPL Data Analytics Dashboard (2008–2025)

This project performs end-to-end data analysis on IPL match data using Python, SQL and Power BI.

## Tools & Technologies
- Python (Pandas, NumPy)
- SQL
- Power BI
- Excel

## Project Workflow
1. Data Cleaning using Python (Pandas)
2. Data Storage using SQLite
3. Data Analysis using SQL queries
4. Dashboard Creation using Power BI

## Dashboard Insights
- Top Run Scorers
- Top Wicket Takers
- Runs Distribution by Over
- Runs by Team
- Match Count and Total Runs
